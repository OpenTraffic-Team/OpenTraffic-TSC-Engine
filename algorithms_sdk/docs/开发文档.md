## 快速开始

### 安装

```bash
# 从源码安装
pip install -e ./algorithms_sdk/

# 安装开发依赖
pip install -e ./algorithms_sdk/[dev]
```

### 5分钟上手

```python
from algorithms_sdk import AlgorithmSDK

# 1. 创建SDK实例
sdk = AlgorithmSDK(
    mode="cityflow",
    config_path="config/test_cityflow.json",
    algo_version="v1"
)

# 2. 准备数据
state = {
    "XML_CNL": {
        "XML_CNL_N_0": ["v1", "v2"],
        "XML_CNL_W_1": ["v3"]
    }
}
vehicles = {
    "v1": {"speed": 5.0, "running": "1"},
    "v2": {"speed": 3.0, "running": "1"},
    "v3": {"speed": 0.0, "running": "0"}
}
sdk._adapter.set_vehicles(vehicles)

env_state = {
    "phases": [1, 2],
    "currentPhase": 1,
    "phaseTime": 30,
    "currentPlan": "1",
    "timestamp": 1700000000
}

# 3. 获取决策
result = sdk.step(state, env_state)
print(f"推荐相位: {result.action.phase}")
print(f"推理耗时: {result.inference_time_ms:.2f}ms")

# 4. 查看监控
metrics = sdk.get_metrics()
health = sdk.get_health_status()

# 5. 关闭
sdk.close()
```

## 架构设计

### 模块结构

```
algorithms_sdk/
├── __init__.py              # 包入口，导出主要API
├── config.py                # 配置管理
├── core/                    # 核心模块
│   ├── sdk.py              # AlgorithmSDK 主类
│   ├── types.py            # 数据类型定义
│   ├── constants.py         # 常量定义
│   └── exceptions.py        # 异常类
├── adapters/               # 适配器层
│   ├── base.py             # BaseAdapter 基类
│   ├── simulation.py       # 仿真适配器 (CityFlow/SUMO)
│   └── production.py       # 生产适配器 (中间件)
├── monitoring/             # 监控模块
│   ├── metrics.py          # 性能指标收集
│   └── health.py          # 健康检查
├── utils/                  # 工具模块
│   └── converter.py        # 数据格式转换
└── examples/               # 示例代码
```

### 核心组件

| 组件 | 说明 |
|------|------|
| `AlgorithmSDK` | 统一入口类，对外提供 `step()` 等核心接口 |
| `SimulationAdapter` | 仿真适配器，封装 CityFlow/SUMO 数据格式转换 |
| `ProductionAdapter` | 生产适配器，连接 Redis 中间件 |
| `AdvancedControl` | 算法核心控制器（位于 `algorithms/` 模块） |

### 数据流

```
仿真环境                    SDK                      算法核心
   │                        │                          │
   ├─── state (车辆数据) ──►│                          │
   ├─── env_state ─────────►│                          │
   │                        ├─── 格式转换 ────────────►│
   │                        │                          ├──► 算法推理
   │                        │◄── action (相位) ────────│
   │◄── phase ──────────────│                          │
```

## 核心API

### AlgorithmSDK

主类，提供统一的算法调用接口。

#### 初始化

```python
sdk = AlgorithmSDK(
    mode: str = "cityflow",           # 运行模式: cityflow | sumo | production
    config_path: str = None,          # 路口配置文件路径
    mq_config_path: str = None,       # 中间件配置（仅 production 模式）
    algo_version: str = "v4",         # 算法版本: v1 | v2 | v3 | v4
    logger: Callable = None,          # 日志回调函数，默认 print
)
```

#### 核心方法

##### `step(state, env_state) -> DecisionResult`

执行一步决策。

**参数：**
- `state`: 仿真环境状态（CityFlow/SUMO 格式）
- `env_state`: 信号机环境状态

**返回：**
- `DecisionResult`: 决策结果对象

```python
result = sdk.step(state, env_state)
print(result.action.phase)           # 相位名称，如 "phase1"
print(result.action.phase_index)      # 相位索引（从0开始）
print(result.inference_time_ms)        # 推理耗时（毫秒）
```

##### `get_metrics() -> MetricsData`

获取性能指标。

```python
metrics = sdk.get_metrics()
print(metrics.total_decisions)        # 总决策次数
print(metrics.successful_decisions)    # 成功决策次数
print(metrics.failed_decisions)        # 失败决策次数
print(metrics.avg_inference_time_ms)  # 平均推理耗时
```

##### `get_health_status() -> HealthStatus`

获取健康状态。

```python
health = sdk.get_health_status()
print(health.is_healthy)               # 是否健康
print(health.memory_usage_mb)          # 内存占用（MB）
print(health.error_count)              # 错误次数
print(health.last_decision_time)       # 最后决策时间
```

##### `reset()`

重置统计指标和内部状态。

##### `close()`

关闭 SDK，释放资源。

#### 上下文管理器

```python
with AlgorithmSDK(mode="cityflow") as sdk:
    result = sdk.step(state, env_state)
    # 自动调用 close()
```

## 使用示例

### 场景一：CityFlow 仿真

适用于强化学习算法训练和评估。

```python
from algorithms_sdk import AlgorithmSDK

# 创建SDK
sdk = AlgorithmSDK(
    mode="cityflow",
    config_path="config/路口配置.json",
    algo_version="v4"
)

# 设置车辆数据
sdk._adapter.set_vehicles({
    "v1": {"speed": 5.0, "running": "1"},
    "v2": {"speed": 0.0, "running": "0"},
})

# 运行仿真
for episode in range(100):
    for step in range(1000):
        # 获取仿真状态
        cityflow_state = cityflow_engine.get_lane_info()
        env_state = signal_controller.get_state()

        # 获取算法决策
        result = sdk.step(cityflow_state, env_state)

        # 执行决策
        cityflow_engine.set_phase(result.action.phase)

    # 回合统计
    print(f"Episode {episode}: {sdk.get_metrics()}")

sdk.close()
```

### 场景二：SUMO 仿真

适用于交通仿真研究。

```python
sdk = AlgorithmSDK(
    mode="sumo",
    config_path="config/路口配置.json",
    algo_version="v4"
)

import traci

while traci.simulation.getMinExpectedNumber() > 0:
    traci.simulationStep()

    # 获取SUMO状态
    sumo_state = traci_handler.get_state()
    env_state = signal_controller.get_state()

    # 获取决策
    result = sdk.step(sumo_state, env_state)

    # 执行相位
    traci.trafficlight.setPhase("intersection_1", result.action.phase_index)

sdk.close()
```

### 场景三：生产环境

连接真实信号机，通过中间件通信。

```python
sdk = AlgorithmSDK(
    mode="production",
    mq_config_path="config/mq_config.json",
    config_path="config/路口配置.json"
)

# 启动自动运行
sdk._adapter.start_auto_run()

# 定期检查健康状态
import time
while True:
    health = sdk.get_health_status()
    if not health.is_healthy:
        print(f"警告: {health.message}")
    time.sleep(60)

sdk.close()
```

## 配置说明

### 路口配置文件

JSON 格式，定义路口的几何参数、相位方案、车道映射等。

示例：`config/test_cityflow.json`

```json
{
    "intersection_id": "XML_CNL",
    "phases": [
        {"index": 0, "name": "东西直行", "duration": 30},
        {"index": 1, "name": "南北直行", "duration": 30}
    ],
    "lanes": {
        "XML_CNL_N_0": {"movement": "N_through", "capacity": 1800},
        "XML_CNL_W_1": {"movement": "W_left", "capacity": 900}
    }
}
```

### 中间件配置

生产模式下需要配置 Redis 连接信息。

示例：`config/mq_config.json`

```json
{
    "redis": {
        "host": "127.0.0.1",
        "port": 6379,
        "db": 0,
        "password": ""
    },
    "mq": {
        "host": "127.0.0.1",
        "port": 5672,
        "username": "guest",
        "password": "guest"
    }
}
```

## 数据格式

### state 参数格式

**CityFlow 格式：**
```python
state = {
    "路口ID": {
        "车道ID": ["vehicle_id1", "vehicle_id2"],
        "车道ID2": []
    }
}

# 或直接传入:
state = {
    "XML_CNL_N_0": ["v1", "v2"],
    "XML_CNL_W_1": ["v3"]
}
```

### env_state 参数格式

```python
env_state = {
    "phases": [1, 2],              # 可用相位列表
    "currentPhase": 1,              # 当前相位索引
    "phaseTime": 30,                # 当前相位已运行时间（秒）
    "currentPlan": "1",             # 当前方案名称
    "timestamp": 1700000000         # 时间戳（可选）
}
```

### DecisionResult 返回格式

```python
@dataclass
class DecisionResult:
    action: PhaseAction              # 决策动作
    timestamp: float                # 时间戳
    inference_time_ms: float        # 推理耗时（毫秒）
    algorithm_version: str           # 算法版本
```

## 异常处理

### 异常类型

| 异常 | 说明 |
|------|------|
| `SDKError` | SDK 基础异常 |
| `SDKInitError` | SDK 初始化错误 |
| `LicenseExpiredError` | 许可证过期 |
| `AlgorithmError` | 算法执行错误 |
| `AdapterError` | 适配器错误 |
| `ConfigError` | 配置错误 |

### 使用示例

```python
from algorithms_sdk import AlgorithmSDK
from algorithms_sdk.core.exceptions import SDKError, SDKInitError

try:
    sdk = AlgorithmSDK(mode="cityflow")
    result = sdk.step(state, env_state)
except SDKInitError as e:
    print(f"初始化失败: {e}")
except SDKError as e:
    print(f"SDK错误: {e}")
finally:
    if 'sdk' in locals():
        sdk.close()
```

## 监控与诊断

### 内置监控

SDK 自动收集以下指标：

- 总决策次数
- 成功/失败决策次数
- 平均推理时间
- 内存占用
- 错误计数

### 自定义监控

使用 `monitoring` 模块：

```python
from algorithms_sdk.monitoring import MetricsCollector, HealthChecker

# 创建指标收集器
metrics = MetricsCollector(window_size=1000)

# 记录决策
metrics.record(
    inference_time_ms=5.2,
    decision="phase1",
    success=True
)

# 获取统计
summary = metrics.get_summary()
print(summary)

# 健康检查
health = HealthChecker()
status = health.check()
print(status)
```

### 工具函数

数据格式转换：

```python
from algorithms_sdk.utils import StateConverter

# 传感器格式 -> CityFlow格式
cityflow_state = StateConverter.sensor_to_cityflow(sensor_state)

# CityFlow格式 -> 算法内部格式
algo_state = StateConverter.cityflow_to_algorithm(cityflow_state, vehicles)
```

## 扩展开发

### 添加新的仿真平台

1. 创建适配器类继承 `BaseAdapter`：

```python
from algorithms_sdk.adapters.base import BaseAdapter

class NewSimAdapter(BaseAdapter):
    def __init__(self, mode, config_path=None, logger=None, **kwargs):
        super().__init__(mode, config_path, logger, **kwargs)
        # 初始化逻辑

    def step(self, state, env_state):
        # 1. 转换数据格式
        # 2. 调用算法核心
        # 3. 返回结果
        return action
```

2. 在 `AlgorithmSDK._initialize()` 中注册：

```python
if self.mode == Mode.NEWSIM:
    from your_module import NewSimAdapter
    self._adapter = NewSimAdapter(...)
```

### 添加新的算法版本

在 `core/types.py` 的 `AlgorithmVersion` 枚举中添加：

```python
class AlgorithmVersion(Enum):
    V5_NEW_ALGORITHM = "v5"
```
